# Design Documentation (`docs/design/`)

This directory holds internal design proposals, build specifications and
process notes — the working documents a decision is argued in *before* it
becomes an ADR.

- **User & Operator Manual**: authored chapters and reference manuals live in `usr/share/doc/mios/`.
- **Decision records**: accepted decisions live in `usr/share/doc/mios/adr/`, where the ADR template, the ADR index and `check_template_conformance` all reach them.
- **Process & History**: the documents here are process artifacts retained for reference and lineage.

> Renamed from `docs/agy/`. The old name was an agent's name, and Law 5
> (UNIFIED-AI-REDIRECTS) admits no vendor-specific agent or product names in
> code or docs. The `AGY-####` identifiers inside these documents are
> historical task IDs and are left alone: rewriting them would break the
> lineage the directory exists to preserve.
