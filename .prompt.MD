# MiOS report prompt

Canonical report-generation prompt:

- [`.mios/system-prompt.md`](.mios/system-prompt.md)

Use the canonical prompt for FOSS, OCI, CI/CD, immutable-OS, supply-chain,
and local AIOS research reports. It contains:

- a mandatory first-action repository bootstrap protocol for remote/cloud
  agents, including clone/fetch/verification and fail-closed behavior;
- links and bootstrap order for `mios.git`, `mios-bootstrap.git`, and
  `mios-dev-loop`;
- the MiOS architecture and repository ownership boundary;
- upstream evidence, licensing, security, and reproducibility rules;
- the required report schema and decision record;
- commit-submission context required for every change handoff;
- authentication profiles that keep credentials out of prompts and reports.

This root file is a shortcut, not a second prompt contract. Read the complete
`.mios/system-prompt.md` before producing a report or change submission.

## External Artifact Agents

Before generating or accepting any artifact, read the canonical artifact
publisher contract: [`.agents/agents/artifact-publisher.md`](.agents/agents/artifact-publisher.md).
The machine-readable counterpart is
[`.agents/subagents.json`](.agents/subagents.json); both are authoritative and
must remain aligned. The evidence and upstream sources behind the OCI and AI
training-data gates are recorded in
[`docs/research/spike-artifact-publisher-oci-and-training-data.md`](docs/research/spike-artifact-publisher-oci-and-training-data.md).

External agents must fetch each MiOS repository before work, preserve dirty
worktrees, and create candidate artifacts only in their own isolated external
workspace. They must not write generated artifacts into a MiOS repository until
the artifact-publisher contract and its validation evidence are satisfied.
On each daily run, fetch repositories, inspect upstream releases, security
advisories, and relevant specifications, then emit an alert for security,
compatibility, provenance, or validation failures; emit a concise no-change
status when no alert is warranted.
